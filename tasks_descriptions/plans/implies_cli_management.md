# План: Управление импликациями (implies) через CLI

## 1. Цель
Обеспечить полноценный CLI-интерфейс для управления механизмом `implies` в реестре HSM. Это позволит пользователям настраивать сложные связи между компонентами (например, проброс ENV из библиотеки в сервис) без ручного редактирования YAML-файлов.

## 2. Архитектурные изменения

### 2.1 Обновление моделей
- [ ] Обновить `ServiceManifest` в [`src/hyper_stack_manager/models.py`](src/hyper_stack_manager/models.py), добавив поле `implies` (по аналогии с `LibraryManifest`). Это позволит сервисам также влиять на другие компоненты.

### 2.2 Расширение RegistryManager
- [ ] Добавить метод `add_implication(component_type, name, target, value)` для добавления связи.
- [ ] Добавить метод `remove_implication(component_type, name, target)` для удаления связи.
- [ ] Добавить метод `add_option_implication(group_name, option_name, target, value)` для связей внутри групп.

### 2.3 Реализация CLI
- [ ] Создать подкоманды `implies` для `library`, `service` и `group option`.
- [ ] Реализовать парсинг параметров:
    - Для сервисов: поддержка пар `KEY=VALUE` (превращаются в `params`).
    - Для групп: поддержка позиционных значений (имя выбранной опции).
- [ ] Обновить команду `registry show`, чтобы она наглядно отображала текущие импликации.

## 3. Шаги реализации

### Шаг 1: Модели и Ядро
1.  Модификация модели `ServiceManifest`.
2.  Реализация логики в `RegistryManager`. Важно использовать `ruamel.yaml` для сохранения комментариев пользователя при обновлении файлов.

### Шаг 2: Команды CLI
1.  Добавление подкоманд в [`src/hyper_stack_manager/cli/registry.py`](src/hyper_stack_manager/cli/registry.py).
2.  Реализация логики сопоставления `target_id` (например, `service:postgres`) с типом данных (словарь параметров или строка выбора).

### Шаг 3: Валидация и Тесты
1.  Написание Unit-тестов для новых методов `RegistryManager`.
2.  Написание интеграционных тестов в `hsm_sandbox`, подтверждающих, что добавленные через CLI связи корректно отрабатывают при `hsm sync`.

## 4. Ожидаемый результат
Пользователь может настроить стек любой сложности исключительно командами:
`hsm registry library implies add auth-lib service:postgres db_name=auth_db`
